# Blinkit Sales Analysis Dashboard

## Project Overview

This project is an interactive **Power BI dashboard** designed to analyze Blinkit grocery sales data. It provides insights into sales performance, product categories, outlet characteristics, and customer ratings.

The dashboard brings key business metrics and visualizations together to help understand sales trends and compare outlet and product performance.

## Dashboard Features

### Key Performance Indicators (KPIs)
- **Total Sales** – Overall sales generated.
- **Average Sales** – Average sales value.
- **Total Items** – Total number of items.
- **Average Rating** – Average rating.

### Sales Analysis
- **Sales by Item Type:** Compares sales across different product categories.
- **Sales by Fat Content:** Analyzes sales distribution by item fat content.
- **Sales by Outlet Size:** Compares sales across different outlet sizes.
- **Sales by Outlet Location:** Shows sales distribution by outlet location type.
- **Sales by Establishment Year:** Examines sales across outlet establishment years.
- **Outlet Performance:** Compares total sales, total items, average sales, and average ratings across outlet types.
- **Item Visibility vs. Sales:** Explores the relationship between item visibility and outlet sales, segmented by item type.

### Interactive Filters
The dashboard includes filters for:
- Outlet Type
- Outlet Size

These filters allow users to explore the data from different outlet perspectives.

## Tools & Technologies

- **Microsoft Power BI** – Dashboard development and visualization
- **Power Query** – Data preparation and transformation
- **DAX** – Measures and KPI calculations

## How to Use

1. Clone or download this repository.
2. Open the `.pbix` file using Microsoft Power BI Desktop.
3. Interact with the dashboard visuals.
4. Use the Outlet Type and Outlet Size filters to explore different sales perspectives.
