# Zomato Sales Analysis Dashboard

## Project Overview

This project is an interactive **Power BI dashboard** built to analyze Zomato restaurant and order data. It explores revenue, order volume, customer ratings, delivery performance, cuisine preferences, and restaurant types across different cities.

The dashboard helps identify sales patterns and compare restaurant performance using interactive visualizations.

## Dataset Overview

The project uses `Zomato_Data.csv`, containing **1,000 records and 11 columns**.

| Column | Description |
|---|---|
| Order_ID | Unique order identifier |
| City | City where the restaurant operates |
| Cuisine | Cuisine category |
| Restaurant_Type | Type of restaurant |
| Has_Online_Delivery | Online delivery availability |
| Is_Table_Booking | Table booking availability |
| Cost_for_Two | Approximate cost for two people |
| Order_Amount | Order amount |
| Delivery_Time_Mins | Delivery time in minutes |
| Rating | Restaurant rating |
| Votes | Number of customer votes |

## Dashboard Features

### Key Performance Indicators (KPIs)

- **Total Revenue** – Overall revenue generated.
- **Total Orders** – Total number of orders.
- **Average Order Value** – Average value per order.
- **Average Delivery Time** – Average delivery time in minutes.

### Sales and Performance Analysis

- **Revenue by Cuisine:** Compares revenue generated by different cuisine categories.
- **Orders by Online Delivery:** Shows the distribution of orders based on online delivery availability.
- **City-wise Performance:** Analyzes average delivery time and average rating across cities.
- **Revenue by City:** Compares revenue generated across different cities.
- **Restaurant Type Analysis:** Compares revenue, order count, and average delivery time across restaurant types.

### Interactive Filters

The dashboard includes slicers for:
- City
- Cuisine
- Restaurant Type

These filters allow users to explore performance across different locations, cuisines, and restaurant categories.

## Tools & Technologies

- **Microsoft Power BI** – Dashboard development and visualization
- **Power Query** – Data preparation and transformation
- **DAX** – Measures and KPI calculations
- **CSV** – Dataset format

## How to Use

1. Clone or download this repository.
2. Open `Zomato_dashboard.pbix` using Microsoft Power BI Desktop.
3. If prompted, update the data source path to `Zomato_Data.csv`.
4. Interact with the dashboard visualizations.
5. Use the slicers to explore city-wise, cuisine-wise, and restaurant-type performance.
