# Hospital Patient Analytics Dashboard

## Project Overview

This project is an interactive **Hospital Patient Analytics Dashboard** developed using Microsoft Power BI. It analyzes hospital patient records to provide insights into revenue, patient volume, length of stay, admission types, department performance, and branch-wise performance.

The dashboard helps explore hospital operations and compare key metrics across departments, branches, and patient groups.

## Dataset Overview

The project uses `hospital_patient_dashboard_data.csv`, containing **1,000 patient records and 12 columns**.

| Column | Description |
|---|---|
| Patient_ID | Unique patient identifier |
| Admission_Date | Date of patient admission |
| Discharge_Date | Date of patient discharge |
| Branch | Hospital branch |
| Department | Medical department |
| Admission_Type | Type of admission |
| Gender | Patient gender |
| Age | Patient age |
| Length_of_Stay | Number of days spent in hospital |
| Billing_Amount | Amount billed to the patient |
| Satisfaction_Rating | Patient satisfaction rating |
| Doctor_Name | Treating doctor's name |

## Dashboard Features

### Key Performance Indicators (KPIs)

- **Total Revenue** – Overall billing amount generated.
- **Average Length of Stay** – Average number of days patients spend in the hospital.
- **Total Patients** – Total patient count.
- **Average Cost Per Person** – Average billing amount per patient.

### Hospital Performance Analysis

- **Revenue by Department:** Compares total revenue generated by each medical department.
- **Department Analysis:** Uses a scatter chart to explore department-level patient volume and performance.
- **Admission Type Distribution:** Shows the distribution of patients across admission types.
- **Branch-wise Revenue:** Compares total revenue generated by different hospital branches.
- **Department Revenue Summary:** Provides a tabular comparison of revenue across departments.

### Interactive Filters

The dashboard includes slicers for:
- Gender
- Department

These filters allow users to explore hospital performance across different patient groups and departments.

## Tools & Technologies

- **Microsoft Power BI** – Dashboard development and visualization
- **Power Query** – Data preparation and transformation
- **DAX** – Measures and KPI calculations
- **CSV** – Dataset format

## How to Use

1. Clone or download this repository.
2. Open `hospital_patient_dashboard.pbix` using Microsoft Power BI Desktop.
3. If prompted, update the data source path to `hospital_patient_dashboard_data.csv`.
4. Interact with the dashboard visuals.
5. Use the Gender and Department slicers to explore the data.
