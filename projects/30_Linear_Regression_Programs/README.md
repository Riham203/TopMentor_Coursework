# 30 Linear Regression Programs for Data Science

## Overview

This repository contains 30 implementations of Linear Regression concepts, covering mathematical foundations, Scikit-Learn workflows, data preprocessing, regularization, statistical diagnostics, robust regression techniques, and deep learning implementations.

The notebook is designed to help understand how Linear Regression works, how to train and evaluate regression models, and how different techniques can improve model performance.

## Topics Covered

### 1. Fundamentals & Mathematics from Scratch
1. Simple Linear Regression using Pure Python
2. Vectorized Ordinary Least Squares using NumPy
3. Gradient Descent Implementation
4. Stochastic Gradient Descent (SGD)

### 2. Scikit-Learn Implementation & Evaluation
5. Basic Scikit-Learn Fit and Predict
6. Model Evaluation Metrics (MSE, RMSE, MAE, R²)
7. Adjusted R-Squared Calculation
8. Train-Test Split Workflow
9. K-Fold Cross-Validation

### 3. Data Preprocessing & Pipeline Integration
10. Handling Categorical Variables (One-Hot Encoding)
11. Feature Scaling using StandardScaler
12. Polynomial Regression Transformation
13. Full Pipeline Assembly

### 4. Regularization Techniques
14. Ridge Regression (L2 Penalty)
15. Lasso Regression (L1 Feature Selection)
16. ElasticNet Regression
17. RidgeCV Hyperparameter Tuning

### 5. Diagnostics & Statistical Inference
18. Statsmodels OLS Diagnostic Summary
19. Multicollinearity Assessment using VIF
20. Residual Analysis & Normality Test
21. Heteroscedasticity Detection using Breusch-Pagan Test
22. Outlier Detection using Cook's Distance

### 6. Advanced & Robust Regression
23. Huber Robust Regression
24. RANSAC Outlier Rejection
25. Quantile Regression
26. Generalized Least Squares (GLS)

### 7. Special Techniques & Deep Learning
27. Logarithmic Target Transformation
28. Linear Regression using PyTorch Autograd
29. Linear Regression using TensorFlow / Keras
30. Feature Importance Plotting
