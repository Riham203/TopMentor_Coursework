# 🤖 AI Data Analysis Agent

An AI-powered data analysis application built using **Python, Streamlit, Google Gemini AI, and Pandas**. This project enables users to upload datasets, ask questions in natural language, and automatically generate Python code to analyze data and create visualizations.

## ✨ Features

- 📂 **Dataset Upload:** Upload CSV and Excel (`.xlsx`) files.
- 👀 **Data Preview:** View uploaded datasets in an interactive table.
- 📊 **Dataset Overview:** Display the total number of rows and columns.
- 💬 **Natural Language Queries:** Ask questions about your data using simple English.
- 🧠 **AI-Powered Analysis:** Use Google Gemini to generate Python analysis code.
- ⚙️ **Automated Execution:** Execute the generated code to obtain analytical results.
- 📈 **Data Visualization:** Generate charts using Matplotlib and Seaborn.
- 📝 **Code Transparency:** View the Python code generated by the AI agent.
- ⚠️ **Error Handling:** Display errors encountered during analysis and code execution.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Riham203/TopMentor_Coursework.git
cd TopMentor_Coursework/projects/AI_data_Analysis
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate the environment.

**macOS / Linux**

```bash
source venv/bin/activate
```

**Windows**

```bash
venv\Scripts\activate
```

### 3. Install dependencies

Create a `requirements.txt` file containing:

```text
streamlit
pandas
matplotlib
seaborn
python-dotenv
google-genai
openpyxl
```

Install the required packages:

```bash
pip install -r requirements.txt
```

### 4. Configure the Gemini API key

Get your API key from [Google AI Studio](https://aistudio.google.com/).

Create a `.env` file in the project directory:

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

Replace the placeholder with your actual API key.

**Security:** Never upload your `.env` file or API key to GitHub.

Add the following to `.gitignore`:

```gitignore
.env
venv/
__pycache__/
*.py[cod]
```

### 5. Run the application

```bash
streamlit run app.py
```

The application will open in your web browser.

## 🚀 How to Use

1. Launch the Streamlit application.
2. Upload a CSV or Excel dataset from the sidebar.
3. Review the dataset preview and its dimensions.
4. Enter a question about your data.
5. Click **Run Analysis**.
6. Expand the code section to inspect the generated Python code.
7. View the analytical output and any generated charts.

## 💡 Example Questions

You can ask questions such as:

- What is the total sales for each region?
- Which category has the highest sales?
- Calculate the average sales for each category.
- Identify missing values in the dataset.
- Create a bar chart showing sales by region.
- Show the distribution of numerical columns.
- Compare sales across different categories.

The questions should match the columns and information available in your uploaded dataset.

## 🧠 How It Works

1. **Data Loading:** Pandas loads the uploaded CSV or Excel file into a DataFrame.
2. **Dataset Inspection:** The agent examines the dataset dimensions, column types, and sample records.
3. **Prompt Generation:** The dataset context and user's question are sent to Google Gemini.
4. **Code Generation:** Gemini generates Python code tailored to the requested analysis.
5. **Code Execution:** The agent executes the generated code against the DataFrame.
6. **Output Capture:** Printed results, execution errors, and Matplotlib figures are collected.
7. **Visualization:** Streamlit displays the analytical output and generated charts.

## ⚠️ Limitations and Security

- A valid Gemini API key and internet connection are required.
- AI-generated code and insights may contain errors and should be verified.
- The current implementation uses Python `exec()` to execute generated code. This is not a secure sandbox. Do not run untrusted generated code in a sensitive environment without proper isolation and security controls.
- Large datasets may require additional memory and processing time.
- The configured Gemini model must be available to your API key.
